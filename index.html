01 / Proje bilgileri

Yapılandırma burada görünecek.

02 / Site analiz motoru

Bu siteyi analiz etme iznim var ve analiz kapsamı kullanım koşullarına uygundur.
Motor GitHub Actions üzerinde çalışır. Aynı alan adındaki sınırlı sayıda HTML sayfasını inceler; başlık, poster, kategori bağlantıları, iframe ve medya URL ipuçlarını raporlar. CAPTCHA/oturum korumasını aşmaz ve videoyu oynatılabilir diye garanti etmez.

03 / Workflow çalıştır

Depoda bu workflow'un bulunduğunu, siteyi analiz etme iznim olduğunu ve token'ın yeterli izinlere sahip olduğunu onaylıyorum.
Workflow ve derleme sonuçları burada görünecek.

Token kaydedilmez. Gerekli en düşük izinleri kullan; iş bitince alanı temizle ve gerekiyorsa token'ı iptal et. Workflow tetiklenince sonuçlar GitHub Actions artefact'larında görünür.

Kurulum sırası

1
Bu ZIP'i GitHub deposuna koy

Dosyaları hedef depoya yükle; `.github/workflows/build-cs3.yml` yolu korunmalı.

2
Actions izinlerini aç

Repo Settings → Actions → General bölümünde workflow izinlerini kontrol et.

3
Mobil panelden çalıştır

Owner, repo, workflow ve branch alanlarını doğrula; izin onayını işaretle.

4
Raporu indir

Actions çalışmasının artifact bölümünden site-analysis.zip çıktısını indir.

5
Gerçek provider şablonunu ekle

Analizden sonra `GeneratedProvider` Kotlin kaynağı üretilir ve Gradle ile `.cs3` derlenmeye çalışılır. Derleme hatası olursa Actions günlüklerinde nedeni görünür. Oynatma uyumluluğu gerçek CloudStream uygulamasında ayrıca sınanmalıdır.

Önemli teknik sınır

Bu paket genel Kotlin provider üreticisi ve CloudStream Gradle proje iskeleti içerir. Yaygın HTML/WordPress seçicileri kullanılır; her sitenin özel AJAX/iframe oynatıcısının otomatik çözüleceği garanti değildir. Derleme ve gerçek oynatma iki ayrı testtir.
